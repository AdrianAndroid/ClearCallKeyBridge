# 2026-11-19 · macOS 目标平台变更

## 决策

用户明确指定本应用运行在 macOS。MVP 的目标平台由 Linux 改为 macOS；Linux 不再是 MVP 交付要求。原有 Linux 方案和历史 change 作为背景记录，不代表当前要求。

## 影响

- 设备输入以 macOS 可用的蓝牙、系统事件和诊断接口为研究对象；具体通道、权限和各键可用性须由实际证据确定。
- 不把系统音量变化当作已证实的耳机按键事件，不伪造 press/release，也不声称可独占或拦截。
- 自检、HID 输出和音频设备检查使用 macOS 能力与权限，不要求 BlueZ、btmon、uinput 或 PulseAudio。
- 单进程架构、learn 隔离、PTT 强制停麦与其余现有动作约束保持不变。
- 本变更只调整规范，不表示 macOS 实机按键监听已经实现或验证。
