# 蓝牙调试指南（ClearCall200）

> 目标：拿到"每个按键 → 哪条 HCI/AVRCP/HFP 报文"的对应表，据此实现 `parser`，
> 尤其是把 `mute` 键对应的私有 AT 指令逆向出来。

## 0. 前置检查

```bash
# 确认蓝牙服务与适配器
systemctl status bluetooth
bluetoothctl list
hciconfig -a

# 允许实时抓 HCI（btmon 一般不需要额外权限）
sudo btmon --version
```

> 如果本机蓝牙适配器不支持 HCI monitor，可用外接适配器 + Wireshark 的 Bluetooth HCI 抓包。

## 1. 抓包（主路径：btmon）

```bash
# 全量抓，落文件，同时终端实时看
sudo btmon -w /tmp/cc200.btsnoop | tee /tmp/cc200.log
```

Wireshark 打开 `cc200.btsnoop` 后常用过滤：

```
# 只看 AVRCP（音量、上下曲、播放暂停）
btavrcp || btl2cap

# 只看 HFP / 通话相关 AT 与 SCO
btatt || btl2cap || bthci_cmd || bthci_evt
```

btmon 终端里更有用的做法是**先清屏，然后只按一个键**，看新增的那几行。

## 2. 采样流程（一次只按一个键）

对每个动作单独采样，并记录：`键 | 手势 | 报文关键字段 | 对应 trigger`

| 序号 | 操作 | 期望触发源 |
|---|---|---|
| 1 | 音量+ 单击 | `volp:click` |
| 2 | 音量+ 长按 2s | `volp:long` |
| 3 | 音量- 单击 | `volm:click` |
| 4 | 通话键 单击（非通话） | `call:click` |
| 5 | 通话键 长按 2s | `call:long` |
| 6 | 通话键 双击 | `call:double` |
| 7 | 通话中按 mute | `mute:click` |
| 8 | 空闲按 mute | **期望无报文**（验证硬件限制） |
| 9 | 来电（用另一台手机拨号） | `call_state=ringing` |
| 10 | 接听 / 挂断 | `active` / `idle` |

## 3. 判读要点

- **AVRCP**：看 `AVRCP: Pass Through - Volume Up / Volume Down / Play / Pause`，
  `Pressed` 与 `Released` 成对出现 —— 这就是做"单击/长按"判定的原始信号：
  按下记录时间，抬起时按持续时间分类。
- **HFP**：看 L2CAP RFCOMM 通道上的 AT 串，典型的有：
  - `AT+CLIP` / `RING` → 来电
  - `ATA`（接听）/ `AT+CHUP`（挂断）
  - `AT+CMUT=0/1`（麦克风静音开关）— **我们的 `mute:click` 就是找这个或它的厂商变体**
  - 若 `AT+CMUT` 不出现，说明是漫步者自定义扩展 AT，需要在 RFCOMM 串里逐条对照，
    方法：通话中按下 mute，逐条记录新出现的 `AT+XXX`，再用重复实验确认。
- **A2DP 状态**：`SBC` 编码，仅用于确认音频链路是否建立（AVRCP 事件依赖它）。

## 4. 长按 / 双击阈值的实测标定

用抓包时间戳统计：
- 长按：同样按键在 `Pressed` 停顿时长分布 —— 取典型值，默认 1500ms
- 双击：两次 `Pressed` 的间隔分布 —— 默认窗口 500ms
- 防抖：同键重复报文的间隔，取 < 50ms 视为抖动

## 5. 常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 按 mute 完全没新报文 | 空闲态不上报（正常） | 通话中再测；仍无则查 RFCOMM 是否被系统 HFP 接管 |
| 抓不到 HFP AT | 系统蓝牙栈直接处理了 HFP，btmon 只显示上层结果 | 用 Wireshark 看 RFCOMM 载荷；或在另一台机做 AG 角色 |
| 一拖二时事件混乱 | 两条 HFP 链路 | 按 L2CAP 句柄（CID/handle）分离后分别判定 |
| AVRCP 事件缺失 | A2DP 未连接或未播放 | 先确保音频链路建立，再按音量键 |
| 蓝牙适配器不支持 monitor | 驱动限制 | 换适配器 / 用 Wireshark + 外接 dongle |
